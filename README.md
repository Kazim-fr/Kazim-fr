## About

I am a **Computer Science & Engineering undergraduate specializing in Blockchain** at **Samrat Ashok Technological Institute (SATI), Vidisha**, with a focused interest in **cybersecurity, software engineering, and security-oriented systems**.

My current direction combines practical cybersecurity with engineering fundamentals. I work with **Python, Java, Bash, PowerShell, networking, Linux, web security, vulnerability assessment, and security tooling**, while continuously developing my understanding of offensive and defensive security.

I am particularly interested in the **SOC Analyst** path, including security monitoring, incident response, threat hunting, log analysis, network security, and understanding attacker behaviour.

Beyond individual security tools, I aim to develop a **product-engineering mindset**: designing systems that are functional, maintainable, secure, and useful in real-world environments.
